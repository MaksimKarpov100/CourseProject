# 🎲 Автоматизированная информационная система «Магазин настольных игр»

Данный проект представляет собой десктопное приложение (АИС), разработанное на платформе **.NET (Windows Forms)** с использованием базы данных **MySQL**. 
Система предназначена для автоматизации учета товаров, управления заказами, ведения клиентской базы и разграничения прав доступа сотрудников магазина.

---

## 🛠 Технологический стек

* **Язык программирования:** C# (.NET Framework)
* **Интерфейс:** Windows Forms (WinForms)
* **СУБД:** MySQL (библиотека `MySql.Data`)
* **Работа с Excel:** Библиотека `EPPlus` (создание отчетов без установленного MS Office)
* **Работа с Word:** Библиотека `DocX` (Xceed) (создание чеков в формате .docx без MS Office)
* **Установщик:** Inno Setup
* **Архитектурные паттерны:** MVC (разделение логики и интерфейса), RBAC (ролевая модель доступа).

---

## 👥 Роли и разграничение доступа (RBAC)

В системе реализовано 3 роли. При авторизации интерфейс динамически перестраивается (скрываются недоступные вкладки в `TabControl`). Все таблицы в интерфейсе защищены от прямого редактирования (`ReadOnly = true`).

### 👑 1. Администратор (Полный доступ)
* **Управление пользователями:** Создание, редактирование, удаление сотрудников, смена паролей, назначение ролей. Защита от удаления самого себя.
* **Управление товарами:** Полный доступ к каталогу (добавление, изменение, удаление, загрузка фото).
* **Управление заказами:** Просмотр, редактирование и **удаление** заказов (доступно только админу).
* **Справочники:** Управление категориями, клиентами и статусами.
* **Специальные возможности:** Резервное копирование БД, восстановление, экспорт/импорт CSV, выгрузка отчетов в Excel.
* **Скидки:** Просмотр правил начисления скидок.

### 📦 2. Товаровед (Склад и Каталог)
* **Управление товарами:** Добавление игр, изменение цен, остатков, загрузка PNG-изображений.
* **Управление категориями:** Создание и редактирование жанров игр.
* **Просмотр заказов:** Может просматривать заказы и менять их статус (например, на «Готов»), но не может создавать новые или удалять их.
* **Отчеты:** Формирование отчетов о выручке за период в Excel.

### 💼 3. Продавец (Работа с клиентами)
* **Новый заказ:** Оформление продажи, выбор клиента, добавление товаров в корзину, автоматический расчет скидки.
* **Управление клиентами:** Добавление новых клиентов и редактирование их данных (маска телефона, валидация).
* **Заказы:** Просмотр заказов, смена статусов, **печать чека в Word**.
* **Просмотр товаров:** Только чтение каталога (без права изменения цен и остатков).

## ⚙️ Подробное описание функционала

### 1. Авторизация (`LoginForm`)
* Проверка логина (от 4 до 32 символов) и пароля (от 8 до 64 символов).
* Пароль хэшируется (`SHA-256`) и сверяется с БД.
* **Защита:** После 2 неудачных попыток появляется капча. После 3 неудачных — блокировка на 10 секунд (таймер).

### 2. Управление пользователями (`UsersForm`)
* Вывод таблицы: ID, ФИО, Логин, Роль, Телефон.
* **Маскировка (152-ФЗ):** ФИО сокращается до «Иванов И.И.», телефон маскируется «902\*\*\*\*12».
* **Условное форматирование:** Админ — красный, Товаровед — желтый, Продавец — зеленый. Есть легенда.
* Пагинация (10, 25, 50 записей), живой поиск, фильтр по ролям, сортировка.
* **Автоматизация ввода:** Поля «ФИО» автоматически делают заглавной первую букву и буквы после пробела/дефиса.

### 3. Управление товарами (`GamesForm`)
* Вывод таблицы с фото (BLOB), названием, категорией, ценой и остатком.
* **Условное форматирование:** Остаток < 4 (красный), 4-10 (желтый), > 10 (зеленый). Есть легенда.
* **Валидация:** Цена и остаток принимают только цифры. Автозаглавная буква в названии. Фото загружается в формате PNG/JPG.

### 4. Учет заказов (`OrdersListForm`)
* Вывод списка заказов. **Условное форматирование** статусов («Новый» — желтый, «Готов» — зеленый, «Отменен» — красный).
* **Фильтрация:** по номеру, статусу, периоду. **Master-Detail:** показ состава заказа.
* **Печать чека в Word:** Генерация документа через библиотеку `DocX` с шапкой, таблицей, итогами и подписью продавца.
* **Отчет в Excel:** Выгрузка через `EPPlus` с красивым оформлением и подписями.

### 5. Оформление заказа (`OrderAddForm`)
* Выбор клиента, добавление товаров (с проверкой остатков).
* **Автоматический расчет скидки** через `DiscountHelper` (поле заблокировано для ручного ввода).
* **Транзакция БД:** Заказ, состав и списание со склада выполняются атомарно. При сбое — `Rollback`.

### 6. Справочники (`CatalogsForm`)
* Вкладки: Категории, Клиенты, Статусы.
* Таблицы растянуты на весь экран (`Dock = Fill`), защищены от прямого редактирования (`ReadOnly = true`). Удаление с защитой от внешних ключей.

### 7. Специальные возможности (`SpecialForm`)
* **Экспорт в CSV:** Выбор таблиц, сохранение.
* **Резервное копирование:** Вызов `mysqldump.exe` (с умным поиском пути к утилите).
* **Восстановление:** Выполнение SQL-дампа.
* **Отчет в Excel:** Генерация через `EPPlus` с шапкой, рамками и подписями.

## 🚀 Установка и развертывание

### 1. Требования
* Windows 7/10/11.
* Установленный MySQL Server (5.7 или 8.0).
* Пакет .NET Framework 4.7.2 или выше.

### 2. Развертывание БД
1. Откройте MySQL Workbench.
2. Создайте базу данных `board_game_store`.
3. Импортируйте скрипт БД (файл `database.sql`).

### 3. Установка приложения через Inno Setup
Проект поставляется в виде установочного файла **`Setup.exe`**, созданного с помощью программы **Inno Setup**. 
1. Запустите `Setup.exe`.
2. Выберите папку для установки (по умолчанию `C:\Program Files\BoardGameStore`).
3. Установщик автоматически создаст ярлык на рабочем столе и в меню «Пуск».
4. После установки запустите приложение через ярлык.

### 4. Тестовые аккаунты
При первом запуске система автоматически создаст пользователей, если БД пуста:
* **Администратор:** `admin` / `admin1234`
* **Товаровед:** `manager` / `manager1234`
* **Продавец:** `seller` / `seller1234`

## 🔒 Безопасность и особенности
1. **SQL-инъекции:** Все запросы выполняются через параметры (`MySqlCommand.Parameters`).
2. **Пароли:** Хранятся в виде хэшей (SHA-256).
3. **Транзакции:** Обеспечивают целостность данных при оформлении заказа.
4. **Лицензия EPPlus:** Для работы Excel-отчетов используется `ExcelPackage.License.SetNonCommercialPersonal("Студент")`.
5. **Установщик:** Настроен дизайн ярлыка и иконки приложения.
