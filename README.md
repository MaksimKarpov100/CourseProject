# 🎲 Автоматизированная информационная система «Магазин настольных игр»

Данный проект представляет собой десктопное приложение (АИС), разработанное на платформе **.NET (Windows Forms)**. Система предназначена для автоматизации учета товаров, управления заказами и разграничения прав доступа сотрудников магазина настольных игр.

## 🚀 Основные возможности

Система реализует ролевую модель доступа (RBAC), динамически адаптируя интерфейс под текущего пользователя:

### 👑 Администратор
* Управление пользователями (создание, редактирование, удаление, назначение ролей).
* Полный доступ к управлению товарами, категориями и клиентами.
* Удаление заказов (в отличие от других ролей).
* Резервное копирование БД (создание дампов) и восстановление.
* Импорт и экспорт таблиц в формат CSV.
* Формирование финансовых отчетов.

### 📦 Товаровед
* Управление каталогом игр (CRUD-операции: добавление, чтение, обновление, удаление).
* Загрузка и сохранение изображений товаров (в формате BLOB).
* Управление справочником категорий.
* Просмотр заказов и смена их статусов (без права создания).
* Формирование отчетов о выручке в Excel.

### 💼 Продавец
* Просмотр каталога товаров в режиме чтения.
* Управление клиентами (с валидацией номеров телефонов по маске).
* Оформление новых заказов (добавление товаров в корзину).
* **Автоматический расчет скидки** (в зависимости от суммы заказа или праздничных дней).
* Формирование и печать чеков в Word.
* Просмотр и редактирование заказов (смена статусов).

## ⚙️ Установка и запуск

### 1. Требования
* Операционная система Windows 7/10/11.
* Установленный MySQL Server (версия 5.7 или 8.0).
* Visual Studio 2019/2022 с установленным пакетом ".NET desktop development".

### 2. Развертывание базы данных
1. Откройте MySQL Workbench (или phpMyAdmin).
2. Создайте базу данных (например, `board_game_store`).
3. Импортируйте скрипт базы данных (файл `board_game_store_structure.sql`), который находится в корне проекта.

### 3. Настройка подключения
При первом запуске программа может потребовать настроить подключение к БД:
1. Нажмите кнопку **«Настройки БД»** на форме авторизации.
2. Укажите ваш хост (`localhost`), порт (`3306`), имя базы данных, логин и пароль от MySQL.
3. Нажмите «Проверить подключение» и сохраните настройки.

### 4. Тестовые аккаунты
При первом запуске система автоматически создаст тестовых пользователей (если база данных пуста):
* **Администратор:** `admin` / пароль: `admin1234`
* **Товаровед:** `manager` / пароль: `manager1234`
* **Продавец:** `seller` / пароль: `seller1234`

## 📋 Особенности реализации

* **Защита данных (152-ФЗ):** В таблицах реализована маскировка персональных данных (ФИО сокращается до инициалов, номера телефонов маскируются: `902****12`).
* **Безопасность:** Пароли хранятся в БД в виде хэшей (SHA-256). Предусмотрена защита от подбора паролей (блокировка входа на 10 секунд после 3 неудачных попыток и ввод капчи).
* **Бизнес-логика:** При оформлении заказа используется транзакция БД, чтобы гарантировать, что заказ сохранится только в случае успешного списания товаров со склада.
* **Удобство (UX/UI):** Внедрены механизмы «живого» поиска, фильтрации и пагинации. Все таблицы защищены от случайного редактирования пользователем (свойство `ReadOnly = true`).
* **Отчетность:** Выгрузка документов реализована без использования сторонних COM-библиотек (Excel/Word), путем генерации CSV и текстовых файлов с разделителями.
